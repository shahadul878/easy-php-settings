# Plugin Tracker Terms of Service

These terms apply to optional use of **Plugin Tracker**, a service operated by CodeEyes at [https://plugin.codereyes.com/](https://plugin.codereyes.com/).

Easy PHP Settings does **not** use Plugin Tracker unless a site administrator explicitly opts in from **Tools → Easy PHP Settings → About → Privacy & Data Sharing**. Data sharing is disabled by default.

## 1. Service description

Plugin Tracker receives anonymous-to-the-public site metadata so CodeEyes can provide plugin support, compatibility insight, and optional service offers related to Easy PHP Settings.

## 2. What is sent, and when

After opt-in only, the plugin may send:

- Site URL
- WordPress, PHP, and Easy PHP Settings plugin versions
- Server software
- Administrator email address and display name
- Installed plugins and themes (name, version, and active status)

Transmission may occur: once when you opt in; then at most once per week via a scheduled task; at most once per hour during wp-admin use; after plugin updates; and once on plugin deactivation if you had opted in.

## 3. Consent and revocation

You may revoke consent at any time from the About tab. Revoking stops future reports and clears scheduled tracker tasks. Previously sent data is handled under the Privacy Policy.

## 4. No requirement to use the service

The plugin’s PHP settings, debugging, backup, and other features work fully without Plugin Tracker.
